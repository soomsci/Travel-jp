# 기타큐슈 · 유후인 여행 앱

2026년 8월 10~13일 규슈 렌트카 여행용 단일 파일 웹앱.

**https://soomsci.github.io/Travel-jp/**

## 구성

| 탭 | 내용 |
|---|---|
| 일정 | 4일 타임라인. 구간별 거리·소요시간·통행료, 현재 시각 기준 "지금 할 일". 직접 수정·추가 가능 |
| 지도 | 전체 동선 (지도 이미지를 파일에 내장해 오프라인에서도 표시) |
| 렌트카 | 예약 정보, 구간별 통행료, 좌측통행·주유 안내, 비상 연락처 |
| 준비물 | 체크리스트 6개 섹션 |
| 맛집 | 저장해둔 규슈권 43곳, 유형·지역별 |
| 지출 | 실시간 환율, 가계부, 예산 대비 진행률 |
| 정보 | 항공·숙소, 비상 연락처, 기본 일본어 |

## 특징

- **의존성 없는 단일 HTML 파일.** 빌드 도구도 프레임워크도 쓰지 않는다
- **오프라인 동작.** 지도 이미지는 base64로 내장, 기록은 localStorage에 저장
- 홈 화면에 추가하면 앱처럼 쓸 수 있다
- 환율은 [open.er-api.com](https://open.er-api.com), 날씨는 [Open-Meteo](https://open-meteo.com)에서 가져온다. 둘 다 실패하면 수동 입력·평년값으로 넘어간다
- 다크/라이트 테마 모두 지원

## 빌드

`규슈여행.html`이 원본이고, 예약번호·탑승객명을 지운 `index.html`을 만들어 배포한다.
저장소가 공개라 원본은 `.gitignore`에 넣어 두었다.

```bash
python3 build_public.py
```
